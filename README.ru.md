# Описание 😼

Консольное приложение для сбора данных с **zakup.sk.kz**.

Сначала программа собирает номера закупок со страниц поиска, затем открывает карточки и получает подробную информацию. После обработки сохраняет результат в **CSV** — для Excel, BI или дальнейшей работы своими скриптами.

Проект изначально создан **по заказу для компании и её сотрудников**. Сейчас получает обновлённую структуру, удобный вывод в консоль и поддержку трёх языков.

---

# Функции 🛠️

- Поиск по словам или номеру закупки
- Несколько поисковых запросов через запятую
- Выбор статусов: опубликовано / опубликовано предварительное обсуждение
- Фильтры исключения услуг и работ
- Сбор данных с нескольких страниц
- Сохранение номеров найденных закупок для проверки повторов при следующем запуске
- Один конфиг или несколько конфигов в отдельных папках
- Панель процесса: текущий этап, количество закупок, предупреждений и ошибок
- Интерфейс на русском, английском и казахском
- Подробный лог работы
- Экспорт в CSV: ссылка, номер, даты начала и окончания приёма заявок, название, заказчик и сумма

# Быстрый старт 👾

## Требования

- Windows — текущая проверенная среда
- Python 3.12 или новее
- Microsoft Edge
- Интернет
- Git — если скачиваете проект через `git clone`

## Установка

1. Скачайте проект или клонируйте репозиторий:

   ```powershell
   git clone https://github.com/AmbreKitsune/Parser-for-zakup.sk.kz.git
   cd Parser-for-zakup.sk.kz
   ```

2. Создайте виртуальное окружение:

   ```powershell
   python -m venv venv
   ```

3. Установите зависимости:

   ```powershell
   .\venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

4. Запустите программу из корня проекта:

   ```powershell
   .\venv\Scripts\python.exe src/main.py
   ```

## Первый запуск

1. Выберите язык: `ru`, `en` или `kk`.
2. Создайте конфиг по вопросам программы или выберите существующий.
3. Дождитесь завершения сбора.
4. Заберите CSV из `data/output/`.

## Примечания

- Если окружение уже активировано, можно запускать через `python src/main.py`.
- Папка `data/` создаётся автоматически.
- Selenium Manager автоматически подбирает драйвер Edge. Вручную класть `msedgedriver.exe` рядом с программой не нужно.
- Первый запуск браузера может занять больше времени из-за подготовки драйвера.
- Для остановки используйте **Ctrl+C**.

# Настройки 📁

Рабочие файлы собраны в папке **`data/`** в корне проекта.

| Файл или папка | Для чего |
| --- | --- |
| `data/settings.json` | Язык интерфейса |
| `data/config.ini` | Одиночный конфиг поиска |
| `data/configs/<имя>/config.ini` | Конфиги в отдельных папках |
| `data/save_id.txt` | Номера закупок для проверки повторов |
| `data/parser.log` | Подробный лог работы |
| `data/parser.log.1` и другие архивы | Предыдущие логи |
| `data/output/` | CSV с результатами |

Если существует `data/configs/`, программа сначала работает с конфигами из этой папки.

Язык общий для программы. Чтобы его изменить, замените значение `language` в `data/settings.json` на `ru`, `en` или `kk` и перезапустите программу. Можно удалить только `settings.json` — тогда программа снова предложит выбрать язык.

Конфиги лучше создавать через меню. Если `site` отсутствует, пустой или содержит только пробелы, выбранный конфиг удаляется. Программа просит перезапустить её и создать новый.

# Ошибки ❌

**Неправильный ввод в меню**  
Программа покажет сообщение и повторит вопрос. Выберите один из указанных вариантов.

**Конфиг повреждён и удалён**  
Перезапустите программу и создайте новый конфиг. Эта проверка относится к отсутствующему или пустому `site`; другие повреждения файла тоже могут привести к ошибке загрузки.

**Edge не запускается**  
Проверьте, что браузер установлен и есть доступ в интернет. Подробности смотрите в `data/parser.log`.

**Таймаут / не загрузилась карточка**  
Проверьте интернет и доступность сайта, затем повторите запуск. Для карточек программа выполняет до трёх попыток. Если проблема остаётся — отправьте автору лог.

**Работа прервана**  
Причина записана в `data/parser.log`. Не нужно фотографировать всю консоль — лог будет полезнее :D

# Q&A ❓

**Q: Где результаты?**  
**A:** В `data/output/`. CSV создаётся, если собраны новые закупки.

**Q: Почему при повторном запуске новых закупок нет?**  
**A:** Их номера могут уже находиться в `data/save_id.txt`. Для повторного сбора удалите этот файл при остановленной программе.

**Q: Язык влияет на CSV и данные с сайта?**  
**A:** Нет. Переводится интерфейс программы. Заголовки CSV и технические логи остаются на русском, данные сайта сохраняются как получены.

**Q: Можно менять конфиг ручками?**  
**A:** Можно, но на свой страх и риск. Проще создать новый через меню.

**Q: А где EXE и установщик?**  
**A:** Это следующий этап. Здесь пока описан запуск из исходников.

# Ограничения 📢

- Работа зависит от интернета и скорости ответа сайта.
- Изменение структуры сайта может потребовать обновления парсера.
- Капча, anti-bot или другие ограничения сайта могут остановить сбор.
- Автор не может гарантировать отсутствие блокировок со стороны сайта.
- Договоры пока недоступны.
- Меню позволяет выбрать лоты, но текущий сбор подробностей открывает карточки закупок (`advert`). Полноценная работа с лотами требует отдельной проверки и доработки.
- История номеров общая для всех конфигов и не отслеживает изменения в уже найденных закупках.
- Другие операционные системы пока не проверены.
