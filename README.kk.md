# Сипаттама 😼

**zakup.sk.kz** сайтынан деректер жинауға арналған консольдік бағдарлама.

Бағдарлама алдымен іздеу нәтижелерінің беттерінен сатып алу нөмірлерін жинайды, содан кейін карточкаларды ашып, толық ақпаратты алады. Өңдеу аяқталған соң нәтижені **CSV** файлына сақтайды — оны Excel, BI немесе өз скрипттеріңізде пайдалануға болады.

Жоба бастапқыда **компания мен оның қызметкерлерінің тапсырысы бойынша** жасалған. Қазір оның құрылымы жаңартылып, консоль интерфейсі ыңғайлы болып, үш тілге қолдау қосылуда.

- Бірнеше беттен деректер жинау
- Келесі іске қосуда қайталанатын нөмірлерді тексеру үшін сатып алу нөмірлерін сақтау
- Бір конфигурация немесе бөлек бумалардағы бірнеше конфигурация
- Процесс панелі: ағымдағы кезең, сатып алулар, ескертулер және қателер саны

- Толық жұмыс журналы
- CSV экспорты: сілтеме, нөмір, өтінімдерді қабылдаудың басталу және аяқталу күндері, атауы, тапсырыс беруші және сомасы

# Жылдам бастау 👾

## Талаптар

- Windows — қазіргі тексерілген орта
- Python 3.12 немесе одан жаңа нұсқа
- Microsoft Edge
- Интернет
- Git — жобаны `git clone` арқылы жүктесеңіз

## Орнату

1. Жобаны жүктеңіз немесе репозиторийді клондаңыз:

   ```powershell
   git clone https://github.com/AmbreKitsune/Parser-for-zakup.sk.kz.git
   cd Parser-for-zakup.sk.kz
   ```

2. Виртуалды орта жасаңыз:

   ```powershell
   python -m venv venv
   ```

3. Тәуелділіктерді орнатыңыз:

   ```powershell
   .\venv\Scripts\python.exe -m pip install -r requirements.txt
   ```

4. Бағдарламаны жобаның түбірлік бумасынан іске қосыңыз:

   ```powershell
   .\venv\Scripts\python.exe src/main.py
   ```

## Алғашқы іске қосу

1. Тілді таңдаңыз: `ru`, `en` немесе `kk`.
2. Бағдарлама сұрақтарына жауап беріп, конфигурация жасаңыз немесе бар конфигурацияны таңдаңыз.
3. Деректерді жинаудың аяқталуын күтіңіз.
4. CSV файлын `data/output/` бумасынан алыңыз.

## Ескертпелер

- Виртуалды орта белсендірілген болса, `python src/main.py` пәрменін пайдалануға болады.
- `data/` бумасы автоматты түрде жасалады.
- Selenium Manager Edge драйверін автоматты түрде таңдайды. `msedgedriver.exe` файлын бағдарламаның жанына қолмен қою қажет емес.
- Драйверді дайындауға байланысты браузердің алғашқы іске қосылуы ұзағырақ болуы мүмкін.
- Тоқтату үшін **Ctrl+C** басыңыз.

# Баптаулар 📁

Жұмыс файлдары жобаның түбіріндегі **`data/`** бумасында сақталады.

| Файл немесе бума | Мақсаты |
| --- | --- |
| `data/settings.json` | Интерфейс тілі |
| `data/config.ini` | Жеке іздеу конфигурациясы |
| `data/configs/<атауы>/config.ini` | Бөлек бумалардағы конфигурациялар |
| `data/save_id.txt` | Қайталануларды тексеруге арналған сатып алу нөмірлері |
| `data/parser.log` | Толық жұмыс журналы |
| `data/parser.log.1` және басқа мұрағаттар | Алдыңғы журналдар |
| `data/output/` | CSV нәтижелері |

Егер `data/configs/` бумасы бар болса, бағдарлама алдымен осы бумадағы конфигурациялармен жұмыс істейді.

Тіл бүкіл бағдарламаға ортақ. Оны өзгерту үшін `data/settings.json` файлындағы `language` мәнін `ru`, `en` немесе `kk` етіп ауыстырып, бағдарламаны қайта іске қосыңыз. Тек `settings.json` файлын жоюға да болады — бағдарлама тілді қайта таңдауды ұсынады.

Конфигурацияларды мәзір арқылы жасаған дұрыс. Егер `site` жоқ, бос немесе тек бос орындардан тұрса, таңдалған конфигурация жойылады. Бағдарлама қайта іске қосып, жаңа конфигурация жасауды сұрайды.

# Қателер ❌

**Мәзірге қате мән енгізілді**  
Бағдарлама хабарлама көрсетіп, сұрақты қайталайды. Көрсетілген нұсқалардың бірін таңдаңыз.

**Конфигурация бүлінгендіктен жойылды**  
Бағдарламаны қайта іске қосып, жаңа конфигурация жасаңыз. Бұл тексеру жоқ немесе бос `site` мәніне қатысты; файлдың басқа зақымдары да жүктеу қатесіне әкелуі мүмкін.

**Edge іске қосылмайды**  
Браузердің орнатылғанын және интернетке қолжетімділікті тексеріңіз. Толық ақпаратты `data/parser.log` файлынан қараңыз.

**Күту уақыты аяқталды / карточка жүктелмеді**  
Интернетті және сайттың қолжетімділігін тексеріп, қайта іске қосыңыз. Бағдарлама әр карточка үшін үш ретке дейін әрекет жасайды. Мәселе шешілмесе, авторға журналды жіберіңіз.

**Жұмыс тоқтатылды**  
Себебі `data/parser.log` файлына жазылады. Бүкіл консольді суретке түсірудің қажеті жоқ — журнал пайдалырақ :D

# Q&A ❓

**Q: Нәтижелер қайда?**  
**A:** `data/output/` бумасында. CSV жаңа сатып алулар жиналған кезде жасалады.

**Q: Неге қайта іске қосқанда жаңа сатып алулар жоқ?**  
**A:** Олардың нөмірлері `data/save_id.txt` файлында болуы мүмкін. Қайта жинау үшін бағдарлама тоқтап тұрған кезде осы файлды жойыңыз.

**Q: Тіл CSV мен сайт деректеріне әсер ете ме?**  
**A:** Жоқ. Тек бағдарлама интерфейсі аударылады. CSV бағандарының атаулары мен техникалық журналдар орыс тілінде қалады, сайт деректері алынған күйінде сақталады.

**Q: Конфигурацияны қолмен өзгертуге бола ма?**  
**A:** Болады, бірақ өз тәуекеліңізбен. Мәзір арқылы жаңасын жасау оңайырақ.

**Q: EXE мен орнатушы қайда?**  
**A:** EXE файлы мен орнатушыны [Releases](https://github.com/AmbreKitsune/Parser-for-zakup.sk.kz/releases/latest) бөлімінен жүктеуге болады.
